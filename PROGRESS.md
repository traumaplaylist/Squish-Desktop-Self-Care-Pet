- **core/tasks.ts** (23 теста): одноразовые; повторяющиеся = шаблон + экземпляр на каждый подходящий логический день (выполнение экземпляра не трогает шаблон, шаблон отметить нельзя); «Разбить» → 3 пустые подзадачи, пустые удаляются при уходе фокуса; родитель отмечается **только** после того, как пользователь отметил последнюю подзадачу (единственное исключение, CLAUDE.md); ручная отметка разбитого родителя отмечает оставшиеся подзадачи; снятие подзадачи снимает родителя; удаление с подзадачами (и с шаблоном — иначе завтра «воскреснет») + восстановление; перетаскивание порядка; смена дня — невыполненные экземпляры тихо исчезают, одноразовые остаются без «просрочено».

- **core/economy.ts** (16 тестов) — цифры R0. Симуляции SPEC 5.4: **типичный день = 41 монета и 46 энергии** (цель 25), **тяжёлый = 11 энергии** (цель 10), одна вода+чек-ин цель не закрывает, дешёвый предмет (40) — за 1 день, средний (120) ≈ 3 дня, дорогой (340) — 7–9 дней. - **core/rewards.ts** (7 тестов): награды за отметки, перерывы (микро 1/0, длинный 4/3), воду (до цели 1/1, сверх — 0/0); снятие галочки списывает не ниже нуля, повторная отметка платит не больше реально списанного — «доить» галочку нельзя.
- **Хранение:** `tasks.json` (задачи и экономика пишутся через 500 мс после изменения); **ежедневный бэкап** `backups/YYYY-MM-DD/` за 7 дней; повреждённый файл восстанавливается из самого свежего целого бэкапа (битые бэкапы пропускаются).
- **Движок:** смена логического дня в 06:00 (энергия и дневные счётчики с нуля, монеты остаются, тяжёлый день выключается, новые экземпляры, бэкап); награды за перерыв и воду; отмена стакана откатывает его награду.

## Известные баги / риски
- CPU в покое на Windows не замерен. Если > 1–2% — варианты: реже тик дыхания (250 мс), дыхание «приступами», выключение дыхания на батарее.
- В debug при ×60 микро-перерыв длится 0,3 реальной секунды — для просмотра оверлея переключай ×1 и жми «Микро сейчас». Простой ввода в debug всегда в реальных секундах (иначе при ×60 каждые 0,3 с засчитывался бы естественный перерыв).
- Esc регистрируется глобально на время перерыва — пока висит оверлей, Esc в других программах не работает (они и так закрыты оверлеем).
- `setIgnoreMouseEvents(..., { forward: true })` работает только на Windows/macOS; на Linux прозрачные места виджета кликов не пропускают (не цель продукта).

## Проверить руками (Windows)
Установщик: GitHub → репозиторий → вкладка **Actions** → последний зелёный запуск **CI** → внизу **Artifacts** → `Squish-Setup` → скачать zip, внутри `Squish-Setup-0.1.0.exe`. SmartScreen: «Подробнее» → «Выполнить в любом случае» (подписи нет).
1. **Установка:** запустить установщик, выбрать папку, дождаться ярлыка на рабочем столе. Запустить Squish → в правом нижнем углу над панелью задач появился мятный питомец; в трее (стрелка ^ у часов) — его иконка.
2. **Живость:** питомец дышит, моргает раз в несколько секунд; поводи мышкой рядом — глаза следят; клик по питомцу — подпрыгивает.
3. **Прозрачность:** кликни по пустому месту рядом с питомцем (над ним, сбоку) — клик должен попасть в то, что под ним (иконку/окно), а не «в стекло».
4. **Перетаскивание:** зажми питомца и перетащи в другое место. Закрой через трей → «Выход», запусти снова — питомец там же.
5. **Два монитора (если есть):** перетащи на второй монитор, перезапусти — он на втором. Отключи второй монитор — питомец вернулся в угол основного.
6. **Масштаб 125% / 150%:** Параметры → Система → Дисплей → Масштаб. Питомец не размыт, не растягивается, остаётся в углу. Если два монитора с разным масштабом — перетащи между ними туда-обратно 3 раза: размер окна не должен «расти».
7. **Демонстрация экрана:** в Zoom, Teams, Telegram и Discord начни демонстрацию всего экрана (можно с самим собой/тестовый звонок) — у собеседника/в превью питомца НЕ видно. Также Win+Shift+S — на скриншоте питомца нет (так и задумано).
8. **Трей:** правый клик по иконке — меню на русском; «Показать/скрыть питомца» прячет и возвращает; «Выход» закрывает. ПКМ по питомцу открывает то же меню.
9. **Debug-режим (по желанию):** не требуется для проверки.
10. **CPU/RAM:** скачай Process Explorer (Sysinternals), найди все процессы `Squish.exe`, через 1 минуту после запуска запиши суммарный CPU и Private Bytes. Пришли цифры.
11. **Перерывы (День 2).** Самое быстрое — правый клик по питомцу → «Сделать перерыв сейчас»: экран мягко темнеет на всех мониторах, питомец «смотрит вдаль», таймер 20 с, потом «Готово! Хорошая пауза» и экран тает. Проверь: (а) на втором мониторе — затемнение и маленький таймер; (б) Esc на оверлее пропускает перерыв (для «обычной» строгости — только через 5 с, когда появилась кнопка «Пропустить»); (в) печатай в Блокноте, когда над питомцем появилось облачко «Через 30 с отдохнём», и не останавливайся — перерыв дождётся паузы в наборе; (г) когда облачко появилось — отпусти клавиатуру и мышь на 3 секунды: перерыв начнётся сразу; (д) трей → «Пауза» → «30 минут»: при наведении на иконку трея видно «Перерывы на паузе до …», в меню появилось «Возобновить перерывы». Без ручного вызова первый перерыв придёт через 20 мин работы.
12. **Умная пауза (День 3).** Включи Debug не нужно — просто: (а) открой YouTube и разверни видео на весь экран (F) — при наведении на иконку трея: «Тихо: полноэкранный режим», перерыв не придёт, пока смотришь; (б) позвони кому-нибудь в Telegram/Zoom/Discord/Teams (или открой «Запись голоса» Windows и начни запись) — в трее «Тихо: созвон — Telegram», питомец с полуприкрытыми глазами, без облачков; после звонка через ~1 мин придёт перерыв; (в) включи камеру (приложение «Камера») — тоже тихо; (г) во время звонка в меню трея есть «Не считать Telegram созвоном» — нажми, через ≤ 5 с тишина пропадёт (вернуть — пока только удалив строку из `%APPDATA%\Squish\settings.json`, настройки — День 6); (д) **важно:** во время звонка убей Telegram через Диспетчер задач (Ctrl+Shift+Esc → снять задачу) — через ≤ 5 с тишина должна закончиться, а не висеть вечно.
