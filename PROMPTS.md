# Промпты для Claude Code — план на 7 дней

## Как пользоваться
1. Создай папку проекта: `CLAUDE.md` в корень, `SPEC.md` в `docs/`, `PROGRESS.md` в корень.
2. `git init`, первый коммит.
3. Каждый день — новая сессия Claude Code. Первое сообщение — в **Plan mode** (Shift+Tab): смотришь план, потом разрешаешь выполнение.
4. Вставляй «Общее начало» + промпт дня. Кончились лимиты — новая сессия (или Codex): «Общее начало» + «Продолжи день N по PROGRESS.md».
5. Вечером руками прогони «Проверить руками» из PROGRESS.md на своей Windows, баги — первым сообщением следующей сессии.
6. Приоритеты в SPEC: [P0] обязательно, [P1] желательно, [P2] если осталось время. Отстаёте — агент режет P2, потом P1.

## Общее начало (в начало КАЖДОЙ сессии)
```
Прочитай CLAUDE.md, docs/SPEC.md (включая раздел 0 — выводы из отзывов) и PROGRESS.md полностью. Соблюдай правила CLAUDE.md без исключений.
Кратко (5 строк) перескажи текущее состояние по PROGRESS.md, затем план на сегодняшнюю задачу и выполняй.
Если по ходу видишь, что не укладываешься в день — сначала режь [P2], потом [P1], [P0] не режь никогда; что срезал — запиши в PROGRESS.md.
В конце сессии обнови PROGRESS.md: сделано / не доделано / срезано / баги / «Проверить руками» (пошагово) / следующий шаг.
```
